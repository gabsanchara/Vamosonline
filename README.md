# ¡Vamos! — испанский за 30 дней

Учебная платформа: 30 уроков, грамматика с запоминалками, озвучка ElevenLabs, повторение.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm install` | установить зависимости |
| `npm run dev` | запустить локально (http://localhost:5173) |
| `npm run check` | проверить контент (дубли, диалоги, чтение, грамматика) |
| `npm run build` | собрать сайт в папку `dist` |
| `npm run audio` | озвучить недостающие фразы (нужен `.env` с `ELEVENLABS_API_KEY`) |

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. Любой push в ветку `main` запускает `.github/workflows/deploy.yml`: проверка, сборка, публикация.
4. Сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Файл `.env` (ключ ElevenLabs) не загружается: он в `.gitignore`. Готовые mp3 лежат в `public/audio` и публикуются вместе с сайтом.
